# 聊天应用

一个简单的聊天应用，包含登录、注册、好友管理和私聊功能。

## 功能特点

- 用户登录（支持多个用户）
- 注册新账号
- 添加和删除好友
- 与好友进行私聊
- 本地存储聊天记录和好友关系
- 退出登录功能

## 如何使用

1. 打开 `index.html` 文件
2. 使用以下账号登录或注册新账号：
   - 用户名: admin, 密码: 123456
   - 用户名: user1, 密码: 123456
   - 用户名: user2, 密码: 123456
3. 登录后，点击"添加好友"按钮添加好友
4. 在好友列表中点击好友开始聊天
5. 可以删除不需要的好友

## 技术实现

- HTML5 + CSS3 + JavaScript
- 本地存储 (localStorage) 用于保存用户信息、好友关系和聊天记录
- 响应式设计，适配不同屏幕尺寸

## 注意事项

- 聊天记录保存在本地，刷新页面后不会丢失
- 这是一个前端演示应用，没有后端服务器
- 每个好友有独立的聊天记录
- 好友关系和聊天记录只保存在当前浏览器中
